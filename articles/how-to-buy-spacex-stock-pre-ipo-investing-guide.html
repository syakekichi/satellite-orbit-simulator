SpaceXの株は今から買うべきか？未公開株（プレIPO）の投資妙味と具体的な購入ルート・実践手順を徹底解説

テスラ株が過去10年間で数十倍に急騰した歴史を目の当たりにし、「次の歴史的メガリターンを生み出すのは、未公開のまま巨大化を続けるSpaceX（スペースX）ではないか」と考える個人投資家や富裕層が世界中で急増しています。

現在、SpaceXは証券取引所に上場していないプライベートカンパニー（未公開企業）ですが、実は一定の資金（数百万円〜数千万円程度）があれば、セカンダリー（流通）市場を通じて個人でもプレIPO株式にアクセスすることが可能です。

本記事では、「今からSpaceX株を買うべきかどうかの投資判断」を財務と将来性から検証し、実際に未公開株を購入するための具体的なプラットフォーム、購入スキーム（SPV）、手数料や法的要件、そして日本居住者が投資する際の実践手順をわかりやすくレクチャーします。

1. 投資判断：今からSpaceX株を買うべきか？

① 企業評価額の推移とアップサイド

SpaceXの企業価値評価額（バリュエーション）は、驚異的なペースで切り上がってきました：

【SpaceXの企業評価額（推定調達ラウンド推移）】
・2019年 : 約 330 億ドル
・2021年 : 約 740 億ドル
・2022年 : 約 1,270 億ドル
・2024年 : 約 2,100 億ドル
・2026年 : 約 2,500億〜3,000 億ドル（約38兆〜45兆円）

「すでに3,000億ドル規模に達している企業に、まだ大きなアップサイドがあるのか？」という疑問が生じます。しかし、機関投資家が強気姿勢を崩さない理由は以下の3点です：

  • Starlinkのスピンオフ（分離上場）IPOの期待： Starlink単体でも時価総額数千億ドル規模が見込まれ、SpaceX本体株主にはスピンオフ時の株式割り当てや評価向上の恩恵があります。
  • Starshipによる宇宙輸送の独占： 完全再使用型のStarshipが商用化されれば、月面アルテミス計画や防衛衛星網、商業宇宙ステーション輸送など、世界の宇宙インフラ予算を独占的に獲得します。
  • 1兆ドル〜数兆ドル企業へのシナリオ： 宇宙通信・防衛・輸送の3大インフラを独占するプラットフォーマーとしてのポテンシャルは、現在のNVIDIAやAppleと同等以上の規模に拡大する余地を秘めています。

⚠️ 把握しておくべきリスク要因

非上場株のため、クリック一つで売却することはできません。IPOや会社主導の買い戻し（テンダーオファー）まで数年間の資金ロックアップが発生します。また、キャリーフィーやマスク氏のキーマンリスクにも留意が必要です。

2. 未公開株を購入する仕組み（SPVとは？）

未公開企業であるSpaceXの株主名簿に個人が直接名前を載せることはSEC規制上困難なため、**SPV（Special Purpose Vehicle：特別目的会社）**を経由したスキームが利用されます：

┌─────────────────┐       ┌─────────────────┐       ┌─────────────────┐
│ 元の株主        │       │ SPV (信託/LLC)  │       │ 個人投資家      │
│ (従業員/初期VC) │ ───> │ ・株式を保有    │ <─── │ ・出資して      │
│ ・株式を売却    │       │ ・名簿上の株主  │       │   持分受益権取得│
└─────────────────┘       └─────────────────┘       └─────────────────┘

退職する従業員や初期投資家が手放す株式をプラットフォームが組成したSPVが買い取り、投資家はそのSPVの持分を購入することで、実質的にSpaceX株のエクスポージャー（経済的権利）を保有します。

3. 主なセカンダリー取引プラットフォーム

  • Forge Global（フォージ・グローバル）： NYSE上場の最大手プラットフォーム。SpaceX株の流動性が最も高い。通常最低投資額10万ドル〜。
  • EquityZen（エクイティゼン）： 最低投資額が2万ドル〜5万ドル程度と比較的参入しやすい老舗。
  • Linqto（リンクト）： 最低投資額1万ドル程度から小口投資可能なアプリ型プラットフォーム。
  • Hiive（ハイブ）： 機関投資家・富裕層向けにリアルタイムの板情報マッチングを提供する新鋭。

4. 日本居住者が投資する際の実践ステップ

ステップ1：米国適格投資家（Accredited Investor）の確認

純資産100万ドル（約1.5億円）以上、または直近2年の年収20万ドル以上（配偶者合算30万ドル以上）の要件を確認。英文の残高証明書等を用意します。

ステップ2：口座開設と本人確認（KYC / W-8BEN）

パスポート、英文住所確認書類を提出し、米国源泉徴収税を軽減するW-8BENフォームに電子署名します。

ステップ3：オファーの確認と発注

SpaceXの取引案件から、株価評価額（インプライド・バリュエーション）と最低投資額を確認して購入注文を入れます。

ステップ4：米ドル送金と契約締結

海外送金で指定カストディ口座に米ドルを送金し、Subscription Agreementに電子署名して完了です。

5. まとめ：資本がある人のための賢いアプローチ

SpaceXは、地球規模の通信網と惑星間輸送を掌握しつつある、21世紀屈指の超巨大独占企業です。5年〜10年の長期で資金を拘束されても問題ない余裕資金がある方にとって、プレIPOでの参入は極めて魅力的な選択肢と言えます。
